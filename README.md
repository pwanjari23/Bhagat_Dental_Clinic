# Dr. Rashmi Bhagat Dental Clinic

A modern, production-grade dental studio website for **Dr. Rashmi Bhagat Dental Clinic** located at Civil Line, Main Road, Saoner, Maharashtra 441107, India.

## ✨ Highlights

- **Bespoke Luxury Medical Aesthetics**: Designed with curated HSL colors (deep forest teal, champagne gold, warm ivory, and soft sage).
- **Tabbed Interactive Navigation**: Instant animated view switching for Home, About, Doctor, Treatments, Reviews, and Contact & Location.
- **Why Choose Us**: Automated sliding carousel featuring key clinic pillars with pause-on-hover/touch functionality.
- **Interactive Patient Journey**: 5-step interactive stepper with touch drag/swipe support and direct appointment booking flow.
- **Treatment Catalog**: Comprehensive details on preventive, restorative, and pediatric dental services with transparent explanations.
- **Interactive Before & After Smile Slider**: Visual proof of dental restoration and whitening transformations.
- **Direct Concierge Integration**: Fixed mobile concierge bar with instant WhatsApp, Phone Call, and Appointment actions.
- **Local SEO & Schema.org**: Fully structured `Dentist`, `LocalBusiness`, and `MedicalBusiness` JSON-LD schema with complete OpenGraph metadata.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, TypeScript)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer-motion.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Playfair Display & Plus Jakarta Sans via `next/font`

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
